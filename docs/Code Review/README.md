## 审查规范

- **审查方式**：只读静态审查（无运行时验证）
- **严重度分级**：P0（确凿 Bug/功能崩溃）> P1（质量/健壮性）> P2（工程实践）> P3（卫生）
- **每轮报告结构**：执行摘要 → 上轮复核 → 新增功能审查 → 全项目质量 → 发现汇总 → 改进建议 → 结论
- **修复闭环**：新报告首节「上轮问题复核」追踪历史问题的修复状态（✅已修复 / ❌未改善 / ⚠️恶化）
