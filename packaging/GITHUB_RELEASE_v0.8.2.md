# Chuni-Eventer v0.8.2

## 更新内容

### 新功能：伴侣（Mate）导入全流程

「其他」页面新增**伙伴**标签页（排第三位），支持把现成的 e-mote（PSB）动画模型一键导入游戏，自制会动的伴侣。整体链路：**获取 PSB → 选 4 个动作 → 拖位置 → 合成预览图 → 绑定角色 → 写入 ACUS**。

- **在线模型仓库**：新增伴侣对话框内置「获取列表」按钮，直接从 [lolicount.top](https://lolicount.top) 在线仓库拉取 PSB 模型（含 NEKOPARA 全员多套服装、命运石之门系列、CHUNITHM 官方角色ユニ/ナイ/イクシア 等 80+ 模型），点「下载并解析」自动完成下载、gzip 解压与解包；也支持浏览本地 PSB 文件。下载与解包在后台线程执行，界面不会卡死。
- **动作匹配**：解析后自动列出模型内全部动画（主/差分分组），只需从中选出 4 个——**待机 / 生气 / 悲伤 / 开心**——系统按官方 mate 的规律自动展开为游戏内 18 个动作槽（Type1=待机，Type2=生气，Type3=悲伤，Type4~18=开心）。带关键词智能预分配（平常/怒る00/哀しい00/喜ぶ00 等标准命名自动选中），可手动改选任意动画。
- **位置可视化预览**：16:9 画布实时显示角色在游戏画面里的大小与位置，直接**拖动立绘**调整，或用数值微调 posX / posY / scale；头部/脚部超出屏幕会显示红色警告。支持加载你自己的游戏截图做背景对照（坐标按实测数据标定）。
- **预览图合成器**：仿系统语音预览图的拼接流程——卡片背景 + 立绘（拖动摆位、滚轮缩放）+ 白框与标签压顶，立绘在白框底边以下自动擦除防止出框。生成 PNG 后，写入伴侣时自动转 BC3 DDS 图标（400×256，与官方 mate 图标同规格）。
- **关联角色联动**：伴侣的名字与立绘来自关联角色（Chara）——下拉绑定现有角色，或点「新建…」直接走完整的新增角色流程，建完自动选中。Mate.xml 的 chara / ddsIllust 字段从所选角色自动读取。
- **系统语音绑定**：可选绑定现有系统语音，或不绑定（systemVoiceId=0，与官方イクシ亚同款填法）。
- **平台自动转换**：PSB 自动 port 为 CHUNITHM 需要的 common 平台，Mate ID 自动分配下一个空闲值。

### 修复

- 修复新增伴侣时下载/解包在界面线程执行导致的卡死与超时报错（大模型解包超时上限提升至 10 分钟，解析中禁止关闭对话框防止线程崩溃）。
- 修复 qfluentwidgets 下拉框 userData 传参错误导致动作选择读取为空的问题。

## 素材来源说明

- lolicount 在线仓库与各模型素材版权归原作者所有，仅供个人学习研究使用，请勿商用。
- 本地 PSB 可以来自任何 e-mote 引擎的游戏资源（NEKOPARA、命运石之门等），需为未加密（pure）PSB。

## 环境要求

- 伴侣功能需要 FreeMote 工具链（懒人包已内置 `.tools\FreeMote`；Lite 版若缺失会在新增时提示）。

## 打包说明

```powershell
powershell -ExecutionPolicy Bypass -File ".\scripts\build_windows.ps1" -Version 0.8.2
```

- **懒人包**：`dist\Chuni-Eventer-v0.8.2.zip`
- **Lite 单 exe**：`dist\release\ChuniEventer.exe`

## 升级提示

- 从 v0.8.1 升级：懒人包建议整包替换；Lite 单 exe 可直接覆盖。
- 建议升级前备份当前 ACUS 与自定义资源目录。
